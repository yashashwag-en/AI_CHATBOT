# AI_CHATBOT
# AI Chatbot (Rule-Based)

A beginner-friendly AI chatbot built using simple **if-else conditional logic** to simulate basic conversation and responses.
This project demonstrates the fundamental concept of how chatbots work before using advanced machine learning or NLP techniques.

---

##  Features

* Responds to basic user inputs using predefined rules
* Simple and easy-to-understand code structure
* Beginner-level project for learning chatbot logic
* Runs directly in the terminal/console

---

##  Technologies Used

* **Python**
* Basic programming concepts

  * if-else conditions
  * user input handling
  * loops

---

##  How to Run the Project

1. Make sure **Python** is installed on your system.
2. Clone this repository:

   ```bash
   git clone https://github.com/your-username/AI_CHATBOT.git
   ```
3. Navigate to the project folder:

   ```bash
   cd AI_CHATBOT
   ```
4. Run the chatbot:

   ```bash
   python chatbot.py
   ```
